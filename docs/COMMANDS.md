# COMMANDS.md — Trae 命令系统说明

> 本文件描述 wiki 项目使用的 Trae 命令**系统**(如何触发、模板结构、autonomy 分级、与项目规则的关系)。单个命令的细节(目标、工具路径、完成判据)在其对应的 `.trae/commands/*.md` 中定义,本文件不重复。

---

## 1. 触发词路由

LLM 在会话中识别用户话语中的触发词,选择对应命令模板。触发词与命令的对应关系在 `.trae/commands/*.md` 的「触发词」段定义,不在本文件重复。

**识别原则**:
- 一个命令可有多个触发词(中文为主)。
- 触发词命中即加载对应模板,不命中的任务按自由对话处理。
- 自由对话中如需引用命令模板,显式说「按 `.trae/commands/<name>.md` 的流程」。

---

## 2. 命令模板五段式结构

每份 `.trae/commands/*.md` 模板包含五段:

| 段 | 含义 |
|----|------|
| **目标** | 此命令要达成的最终结果 |
| **触发词** | 何时调用此命令 |
| **工具路径** | 使用哪些工具与文件 |
| **完成判据** | 何时停止;成功/失败的可验证判据 |
| **autonomy 等级** | 自动 / 一次确认 / 强确认 |

**机械不变量**单独保留(在「完成判据」下方或「机械不变量」小节),不得删除。这些是项目硬约束(如「永不修改 `raw/`」「完成后运行 lint」),非示例性步骤。

---

## 3. autonomy 三级

| 等级 | 触发 | 行为 |
|------|------|------|
| **自动** | 读取 wiki、查询、生成草稿、运行 lint | 直接执行,事后通知 |
| **一次确认** | 新建页面、修改 schema、批量重构 | 一句话请示后执行 |
| **强确认** | 删除内容、跨多页大幅改动、修改 `raw/` 与 `scratch/` | 必须用户明示批准 |

详见 [AGENTS.md](../AGENTS.md)「自治边界」节与 [.trae/rules/project_rules.md](../.trae/rules/project_rules.md)。

## 4. 命令清单(按 glob 列出)

具体命令见 `.trae/commands/` 目录。常用命令:

- `ingest.md` — 摄取新源
- `lint.md` — 健检
- `query.md` — 查询 / 综合回答
- `verify.md` — 核验
- `new-concept.md` — 新建概念页
- `new-theorem.md` — 新建定理页
- `status.md` — 状态概览
- `refactor.md` — 重构
- `audit.md` — 审计

**命令索引不在本文件展开**——以命令模板文件为权威来源,避免重复维护。

## 5. 与 Trae 项目规则的关系

| 配置类型 | 文件位置 | 作用域 |
|---------|---------|------|
| Trae 项目规则 | [`.trae/rules/project_rules.md`](../.trae/rules/project_rules.md) | Trae 始终加载的执行规则 |
| 命令模板 | [`.trae/commands/*.md`](../.trae/commands/) | 按触发词加载的目标导向 SOP |

**规则优先级**(从高到低):
1. 用户当前输入
2. 自定义智能体提示词
3. `user_rules.md`(个人规则,全局)
4. `project_rules.md`(项目规则,Trae 实际加载)
5. `AGENTS.md`(项目身份与地图)
6. `docs/`(详细规范,按需钻取)
