# STRENGTH.md — 定理强弱分类

## 判定原则

定理的强弱应当建立在**条件**与**结论**的基础上——原则上强定理 = **弱条件** + **强结论**。

## 形式化判定

| 取值 | 形式化标准 |
|------|-----------|
| `strong` | 条件较弱（适用广泛函数类/集合），结论较强（导出深层结构或强估计） |
| `standard` | 条件与结论均为中等；通用结论；可在不同场景复用 |
| `weak` | 条件较弱但结论弱，或条件强但结论仍弱（如反例性定理） |

## 示例

| 取值 | 例子 | 判定依据 |
|------|------|---------|
| `strong` | Plancherel 在 $L^2$ 上的等距同构 | 条件：$f \in L^2$（弱）；结论：$\int\|\hat{f}\|^2 = \int\|f\|^2$（强等距） |
| `strong` | Poisson 求和公式 $\sum f(n) = \sum \hat{f}(n)$ | 条件：$f \in \mathcal{S}$（强 Schwartz 类）；结论：精确恒等（强结构性）——但因其连接两种分析范式，仍为 strong |
| `strong` | Dirichlet 算术级数素数定理 | 条件：$(\ell,q)=1$；结论：等差数列有无穷素数——结论强 |
| `standard` | Parseval in $L^2$ | 条件：$f \in L^2$；结论：能量守恒 |
| `standard` | Riemann-Lebesgue 引理 | 条件：$f \in L^1$；结论：$\hat{f}(n) \to 0$ |
| `weak` | 连续函数 Fourier 级数逐点收敛 | 条件：$f$ 连续（弱）；结论：逐点收敛（被 Kolmogorov 1923 反例推翻，强结论不成立） |
| `weak` | Riemann 局部化原理 | 结论较弱（仅给出反例性弱结论：局部化不依赖远处函数值） |

## 使用方式

强弱关系应在「应用」与「推广 / 变体」区段显式标注，例如：

```
本结论强于 [[dirichlet-theorem-on-primes]] 所需的 $L(1,\chi) \neq 0$。
```
